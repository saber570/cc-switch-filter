# SwitchPlus 更新记录

## 1.0.0

- SwitchPlus 启用独立版本线，界面、托盘和安装包统一品牌。保留开源版权和许可文件。
- 合入 Codex 私有请求字段清理、缺失 call_id 工具回执兼容、工具参数重复键修复；与默认开启的 V9 历史过滤和摘要压缩衔接。
- 合入 Codex 用量补记与扫描性能、Windows/WSL 模型目录、窗口位置、macOS 托盘、供应商编辑性能和请求日志筛选修复。
- 保留现有应用标识、安装目录、数据库及保存的端口。Windows EXE 安装器识别早期 4.0.28/4.0.29 为旧版本迁移，其它版本仍执行降级保护。

本版本选取了上游修复，未全量引入上游新应用和隐私脱敏功能。

构建：`corepack pnpm install --frozen-lockfile` 后执行 `corepack pnpm build`。Windows 默认生成 EXE 安装包，macOS 在 Mac 上生成 APP/DMG。请使用同一 Git 提交构建。

验证记录（2026-11-13）：前端 3,746 项、Rust 单元 4,610 项（13 项忽略）、安装数据兼容 3 项通过；类型检查和界面构建通过。新增请求组合测试经过本地模拟 HTTP，未调用真实供应商。新旧 SQL 备份头均可导入。

Windows EXE/MSI 模板编译通过；NSIS 11 个版本比较用例、MSI 6 个升级表用例及图标/安装身份校验通过。模板验证复用了旧程序二进制，不能作为 1.0.0 成品安装包。未执行覆盖安装，macOS 未在本机构建。
